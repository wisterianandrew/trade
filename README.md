#　楽天証券に口座がある人向けの売却サポートツールのひな形です。(自信ないのでそのまま使わないでね)<br>

使うまでの手順<br>
0.main.pyとsub1.pyをダウンロードして特定のフォルダにおく<br>
1.ネットで検索してmarketspeedIIをインストール<br>
2.楽天rssが使えるようにエクセルにアドイン登録（ファイル2種）<br>
3.rakuten.xlsxというファイルを特定のフォルダにおいて、いくつかシートを作成し(codeみてね)、一部のrssは事前に入力しとく<br>
4.save.jsonというファイルも作って同じフォルダにおく<br>
5.main.pyを実行すると画面が開くよ<br>
